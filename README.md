# TrekSummit V2 – Trekking Management Application (MAD-2)

A web application to manage trekking activities with three roles:
Admin, Trek Staff and Trekkers (Users).

Tech stack: Flask (API), VueJS (UI), Bootstrap, SQLite, Redis (caching), Celery (background jobs).
